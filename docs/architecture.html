The flow

Quality checks

Evals

15 cases with known answers. They run after every code change, to check that all workflows still give the right answer.

Rule checker

Checks every agent answer. Sample rules:

  • Prices come only from the parts catalog, never from an agent.
  • A scratch is always priced as a polish, never as a new panel.
  • An agent's note to a rider or inspector never contains a rupee amount.

Step by step

  1. The Detector picks one returned scooter.

    From the active rentals list. The photos taken when the rider picked the scooter up are already stored.

  2. The Detector uploads 4 return photos.

    Front, rear, left and right.

  3. The Detector assesses the damage.

    One click starts the two agents below.

  4. Damage Agent (AI) finds new damage in the photos.

    It compares each return photo with the matching pickup photo and lists only damage that is new.

  5. Estimate Agent (AI) estimates the cost from the parts catalog.

    It picks a repair part for each damage item; the price always comes from the catalog.

  6. The Router decides Path A or Path B.

    It uses fixed rules and is not an agent. Path A, back to the Detector, when the cost is ₹1,500 or less and both agents are confident. Path B, forward to the Inspector, when the cost is over ₹1,500, an agent is unsure, or the photos are too poor to judge.

  7. Path A: Bill Agent (AI) writes the rider's note, the Detector confirms the bill, and the rider pays.

    The amount is taken from the deposit. The payment itself happens outside the app.

  8. Path B: Order Agent (AI) writes the work order, and the Inspector reviews it.

    The Inspector approves or changes each line, then confirms.

  9. Path B: The Detector gets a notification and settles the final amount.

    The Detector collects the extra amount or refunds the rest of the deposit.

Next steps for a production version

Fine-tune the Damage Agent

Train it on 1,000+ real damage photos, so it recognises scratches, dents and cracks on these scooters more reliably.

Add a second Damage Agent as a judge

Train a second, independent agent that checks the first one's answer. When they agree, the answer is more reliable; when they disagree, the return goes to the Inspector.
